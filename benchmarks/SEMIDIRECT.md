# Experimental bounded FP64 semi-direct ERI reuse

Independent implementation inspired by the published semi-direct SCF strategy in NWChem and the direct/in-core/out-of-core tradeoffs documented by Psi4. No third-party source is copied. References: https://nwchemgit.github.io/Hartree-Fock-Theory-for-Molecules.html#direct-and-semidirect-recomputation-of-integrals and https://psi4.github.io/psi4docs/master/scf.html .

Use explicitly with `from pyscf.scf.eri_cache import cached_eri; with cached_eri(mf, max_mb=256): mf.kernel()`. Importing the module does not enable caching. Only ordinary spherical molecular RHF/RKS full-range scalar ERIs are cached; original screening, integrals, contractions and OpenMP driver scheduling remain unchanged. No density fitting, reduced precision or relaxed cutoff. The C-only lookup uses immutable entries, bounded probing and a bounded arena. Every cache belongs to a live CINTOpt; source-array identity and byte snapshots are checked on driver entry. Changed geometry, basis, environment or optimizer bypass the cache. Only one cache per scope; it is released on normal/exceptional exit. Simultaneous calls on the same SCF object are unsupported.

Admission favors primitive-product >=64 or angular sum >=4; this is a caching policy, NOT numerical screening. When space is exhausted, unretained integrals are recomputed normally. The 256 MiB allocation includes table and snapshots, capped to a quarter of current PySCF headroom, not total RSS. Cold allocation/fill occurs within the SCF timer. Cache hit diagnostic counters are OFF for all ordinary and profiled SCF timings and are enabled only for subsequent fixed-density J/K verification. Bookkeeping needed for cache allocation/publication remains part of the algorithm's measured cost.

Local executed checks: 18 synthetic native callback configurations spanning 1/2/4 OpenMP threads, two budgets and three shell counts. Each includes cold/warm, partial capacity, zero integrals, duplicate registration, environment mutation, pointer change, unsupported ncomp, concurrent callers and release fallback. Repeated under UBSan. These are NOT native molecular regression or SCF speed claims.

Controlled molecular comparison: baseline b5b4f1c711b63c1dbb4fb409e979f53852601eca, both enable validated dense BLAS and MGGA SIMD; JK block bound, coalescing, AO cache, native ISA, Qcint and NUMA remain OFF. First one MN15 n=4,t=2 smoke (4 records) then 8 formal cases/64 records: MN15 n=4/8,t=1/2/4, MN15 n=2,t=2 in-core control, PBE n=4,t=2 Coulomb-only SCF control. def2-TZVPP/grid6. Every variant has three fresh-process ordinary SCFs plus one separate profile. Existing energy<=1e-8 Eh and common-density Ne/Exc/Vxc/J/K atol=1e-9 rtol=1e-10 gates unchanged. Each record additionally compares cached J/K with a separate uncached direct optimizer. Reopen all arrays, verify memory and actual hits, and report cold end-to-end medians including regressions. Keep optional and draft until acceptance. Existing PR6 MGGA replay is separate and is not restarted or incorporated.
