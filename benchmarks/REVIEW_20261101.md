## New validation

The review workflow builds this exact event commit and the fixed upstream
checkout with the same portable compiler options and shared libcint/Libxc.
The performance script runs fresh processes in alternating order, with NUMA
disabled and BLAS limited to one thread on both sides. It reports default
candidate kernels separately from explicitly enabled dense-BLAS/SIMD kernels.
It validates convergence, total energy and common-density Ne/Exc/Vxc/J/K,
reopens the saved arrays, and records source, library, thread and memory evidence.

Existing source-specific benchmark successes are supporting evidence, not
acceptance of this combined source tree. The original gradient/scanner failures
on the current DFT base must be checked against upstream with unchanged tests.
Any legacy-scanner-guess diagnostic is reported separately and cannot turn a
failed production test into a passing merge gate.

No benchmark number from an earlier PR is a measured speedup over current
pyscf/pyscf. Results from this new workflow are authoritative for the controlled
cases it actually executes.
